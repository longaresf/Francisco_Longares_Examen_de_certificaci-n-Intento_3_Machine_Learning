# Análisis y predicción de casos de diabetes en pacientes

## Descripción
Este proyecto tiene como objetivo analizar datos de salud de mujeres de ascendencia indígena Pima que viven cerca de Phoenix, Arizona, EE.UU y desarrollar modelos de machine learning para predecir la ocurrencia de casos de diabetes. La importancia de este análisis radica en optimizar el mejor modelo para mejorar la toma de decisiones en relación a los pacientes.

## Estructura del Repositorio
- **data/**: Contiene los datasets utilizados para el análisis y modelado.
- **notebooks/**: Incluye el Jupyter Notebook con el desarrollo de todo el proceso de análisis exploratorio, preprocesamiento y modelado.
- **results/**: Almacena los resultados obtenidos, como métricas de evaluación, Comparacion metricas de rendimiento, Curva ROC  - Random Forest y XGBoost, Histogramas para variables numéricas y Mapa de Calor de la Matriz de Correlación.
- **README.md**: Documento de presentación y guía del proyecto.
